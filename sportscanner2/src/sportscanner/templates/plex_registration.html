Which Path Goes In Plex

The Plex media location must be the managed SportScanner library path as Plex sees it on the Plex host, not the incoming folder and not a container-only path that Plex cannot read.

Manual Fallback

  1. Open Plex and add a new TV Shows library.
  2. Point it at the managed SportScanner library path, not the incoming folder.
  3. On the advanced screen, leave the scanner as Plex TV Series.
  4. Select the SportScanner provider group as the library agent.
  5. Finish library creation, then use the libraries page here to force refresh if metadata stays local.
