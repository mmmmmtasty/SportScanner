How To Use Dashboard

Rescan tip

Use this page as the control point for ingest. Rescan after new files arrive and again after upstream schedule changes so SportScanner can recompute matches and episode numbering before Plex refreshes metadata.

When Plex Looks Stale

If SportScanner already shows the right competition or recording but Plex still shows local:// metadata, old dates, or generic titles, go to Plex Libraries and use Force Refresh. Scan is only for new or renamed files.
